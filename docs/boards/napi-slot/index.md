## Плата роутера MFCR-3308

>**Модуль: NAPI-Slot** \
>**Плата: MFCR-3308.**

Шесть портов Ethernet на одной плате — основа для компактного роутера или маршрутизатора.

- 1xEthernet 100 Мбит/с (нативный порт модуля)
- 4xEthernet через USB
- 1xEthernet через SPI (W5500)
- RS485
- Консоль (USB Type-C)
- RTC
- Слот microSD
